# Checklist de testes antes da entrega

- [ ] Executei `npm install` sem erros.
- [ ] Executei `npm start` e abri `http://localhost:3000`.
- [ ] Os registros iniciais aparecem na tela.
- [ ] Cadastrei um filme e ele apareceu na lista.
- [ ] Cadastrei um jogo e ele apareceu na lista.
- [ ] Editei um registro e conferi a alteração.
- [ ] Excluí um registro de teste.
- [ ] Testei a busca pelo nome e os filtros.
- [ ] Atualizei a página e confirmei que os dados continuam salvos.
- [ ] Reiniciei o servidor e confirmei que os dados continuam salvos.
- [ ] Conferi o relatório por categoria.
- [ ] Preenchi meu nome no README.
- [ ] Conferi se o ZIP e o repositório do GitHub têm os mesmos arquivos.
